# Stroke Type — font credits and licenses

Stroke Type is maintained by [ta-lind](https://github.com/ta-lind). The bundled fonts are third-party work; their designers and converters are credited below.

The 41 original SVG font files come from [Windell H. Oskay’s SVG Fonts collection](https://gitlab.com/oskay/svg-fonts), revision `8c71f2d9e1a5292047bb88e5595a766241b82cc6`. The SVG files retain their original metadata and glyph paths. Generated font data retains that metadata. The plugin displays the selected font’s complete attribution and includes the SIL OFL text; Hershey attribution and restrictions appear with each Hershey font.

EMS fonts and Twin Sans: [SIL Open Font License 1.1](fonts/OFL.txt). Classic Hershey fonts: [Hershey distribution license and acknowledgements](fonts/HERSHEY-LICENSE.txt). These licenses apply to the font software, including its generated representations. The MIT license for the plugin code does not replace the font licenses.

See also the [upstream README](fonts/SOURCE-README.md) and [source revision](fonts/SOURCE.txt).
